Section 01

Viewport & Synchronizer Overview

When multiple devices are loaded inside the Syncpane UI dashboard, scrolling any single iframe triggers the injected __syncpane.js script. The script calculates current scroll percentage relative to the document scroll height and window height, emitting it to the proxy server.

Section 02

Fluid Typography & Scaling

Responsive web layouts often adjust padding, grid columns, and font sizes across breakpoints. This causes the total document scroll height to differ between viewports. Scroll percentage synchronization ensures all screens remain aligned relative to content progression regardless of pixel height variance.

Checkpoint Alpha: Reaching this point indicates that mobile viewports have begun scrolling smoothly.
